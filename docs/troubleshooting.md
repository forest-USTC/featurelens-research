# 常见问题

## 找不到 uv 或 featurelens

未安装 uv 时，先完成[安装指南](installation.md)。源码安装应在项目目录运行 `uv sync --locked`，然后使用 `uv run featurelens`。wheel 安装则先激活安装时的虚拟环境。

## MCP 提示 No module named featurelens

客户端使用了错误的 Python。回到安装环境运行 `featurelens mcp-config`，使用返回的 Python 绝对路径；保存后重新加载该 MCP 服务。无需在客户端设置工作目录。

## 在终端运行 mcp 后没有输出

stdio 服务正在等待客户端输入，不是网页服务。正常接入方式是由 MCP 客户端根据配置启动它。按 Ctrl+C 可退出手动启动的进程。

## 文档可以处理，但静态分析提示找不到 Node 或 Acorn

文档处理不依赖 Node。要分析 JavaScript，需安装 Node.js 22+，再按照[可选模块安装](installation.md#可选解析模块)执行 npm ci。运行 `featurelens doctor --json` 查看环境信息，使用 `featurelens demo --json` 检查完整扫描。

## PDF 提取不到文字

可能是扫描件、图片页或没有文本层。当前没有 OCR；请先用其他工具识别文字，再导入文本。部分页为空时会列出警告。PDF 多栏内容和表格应对照原件核查顺序。

## 导入 TXT / Markdown 编码失败

当前接受 UTF-8 文本，包括 UTF-8 BOM。请将文件另存为 UTF-8 后重试。

## 提示文件已改变或哈希不匹配

工具保存的是某次导入或分析时的证据身份。不要直接编辑数据目录中的原始文件或片段。来源更新后重新导入或分析，再引用新结果；备份损坏时应使用完好的备份重新恢复。

## 导出报告或备份提示文件已存在

工具不会覆盖现有输出。请选择新的文件名。输出目录必须预先存在，输出路径使用绝对路径。

## 提示研究库正在写入

先等其他操作结束。如果所有 FeatureLens 进程都已退出，且上一次曾异常中断，可检查数据目录中的 `.write-lock`。确认没有写入进程后移除这个空锁目录，再重试。不要在仍有进程写入时删除锁。

## 删除后还能恢复吗

可以。`delete` 仅移入回收区，用 `list --status deleted` 查找，再用 `undelete --study-id ID` 恢复。备份也包含回收区。当前没有永久删除或垃圾清理命令。

## 换电脑后如何继续研究

在原电脑使用 `backup`，在新电脑使用 `restore --destination /新的目录`，然后通过 `--data-dir` 或环境变量选择恢复目录。文档与报告可继续使用。外部应用源码不在备份内，静态分析目标需要重新明确指定。

## 工具能自动判断哪个结论正确吗

不能。它检查证据引用、文件身份和记录完整性，不代替业务核验。AI 客户端可以辅助分析，但无证据的结论应保留为未知；测试计划不能当成已经执行的观察。

## 仍无法解决

在 [Issues](https://github.com/forest-USTC/featurelens-research/issues) 提供版本、系统、复现步骤及经过脱敏的错误信息。请使用最小虚构样例，不上传个人研究库、密钥或企业原始资料。
