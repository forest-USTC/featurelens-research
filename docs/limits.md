# 支持范围与资源上限

## 文档

| 格式 | 提取范围 | 来源定位 |
| --- | --- | --- |
| TXT / MD | UTF-8 文本 | 原始行号与行内字符范围 |
| DOCX | 正文段落和顶层表格 | 段落号、表格号与行号 |
| PDF | 可提取的文本层 | 从 1 开始的页码、提取文本字符范围 |

DOCX 不保证覆盖页眉页脚、批注、修订、嵌入对象或嵌套表格。PDF 不支持加密文档或 OCR，多栏顺序和表格可能与视觉排版不同。位置标识不是页面截图坐标。

每次导入上限 20 MiB，DOCX 声明解压总量 64 MiB，PDF 500 页；提取结果最多 200 万字符、5,000 个片段。每段最多 1,500 字符，不跨原始行、段落、表格行或页拼接。提取进程 90 秒超时。超过限制时请拆分文件。

## JavaScript 静态分析

支持已解包目录中的标准 `.js`、`.mjs`、`.cjs`。不直接接受 ASAR、`.app`、TypeScript、JSX 或原生二进制。

扫描仅提取语法节点和文件包含关系；不恢复源码，不执行目标，不解析跨文件调用和数据流。字面搜索不是语义检索。

上限为 180 秒、512 MiB Node 堆、64 MiB 输出、20,000 个目录条目、1,000 个 JS 文件、20,000 个语法节点、单文件 2 MiB、总源码 32 MiB。大型目录请用 `source_paths` 缩小范围。符号链接、解析失败和超大文件会跳过或报错，结果中保留覆盖限制。

## 研究库与备份

本地 JSON 文件加原始材料目录，采用原子写入与跨进程写锁，面向单用户使用。不是多用户数据库，不提供账户权限或服务端部署。

备份原始材料与记录总量上限 256 MiB，最多 10,000 个数据文件。恢复会检查清单、哈希、条目数量及路径，仅写入新目录。文件哈希用于校验完整性，不是对备份来源的认证。

报告含研究者提供的原文与来源路径，不自动匿名化。原始文档、代码和导入的分析结果都可能包含不可信内容；它们是待分析的材料，不是应执行的指令。
